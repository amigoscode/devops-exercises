# SQL

PostgreSQL from your first query to designing a schema that lasts. Every section
opens straight in `psql`, connected to its own database - no Linux needed. Take the
courses in order.

| # | Course | What you practise |
|---|--------|-------------------|
| 01 | [Up and Running with SQL and Databases](01-up-and-running-with-sql/) | PostgreSQL, psql, databases and tables |
| 02 | [SQL and Databases Fundamentals](02-sql-fundamentals/) | queries, filtering, aggregates, changing data, joins |
| 03 | [Advanced Databases](03-advanced-databases/) | indexes, transactions, window functions, triggers, roles and security |
| 04 | [Database Design & Implementation](04-database-design/) | modelling, normalization and two full design exercises |

Open any of them in the Academy: run `./academy.sh` (Windows: `academy.cmd`) from the
repo root.
