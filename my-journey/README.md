# 📓 My Journey

**This folder is yours.** Use it to document what you learn as you work through the
exercises - notes, commands worth remembering, things that tripped you up, wins.

Over time, your fork becomes a **public portfolio of your DevOps journey** - exactly
the kind of thing to show an employer.

## How to use it

1. As you finish each section, jot notes in [`progress.md`](progress.md) (or add
   your own files here - one per course, screenshots, whatever helps you).
2. Commit and push to **your fork**:
   ```bash
   git add my-journey
   git commit -m "notes: finished Linux Fundamentals - file permissions"
   git push
   ```
3. Repeat. Your fork's history becomes a timeline of your progress.

## Will this survive updates?

Yes. When you **Sync fork** to get new exercises, this folder is left untouched -
the upstream course never modifies anything inside `my-journey/`, so your notes and
the new content merge cleanly. Keep all your personal edits in here (don't edit the
course files) and syncing will always be conflict-free.
